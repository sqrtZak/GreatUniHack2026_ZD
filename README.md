Description:
I Language Tutor is a desktop app for practising spoken languages, built with PyQt6. Speak into a microphone or load an audio file (WAV, FLAC, OGG or MP3), and it transcribes your speech offline with WhisperX. A local LLM, run through llama.cpp, then replies as a conversation partner in your chosen language and adds an English translation and grammar feedback on what you said. It supports 20 languages and has Conversational and Review modes. A New Topic button clears the tutor’s memory between scenarios. Everything runs on your own machine, so no audio or text is sent to an external service, and it uses your GPU if CUDA is available.
